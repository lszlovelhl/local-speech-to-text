## 一、项目概述

开发一个 **B/S 架构的本地语音识别 Web 应用**。用户通过浏览器录音或上传音频文件，后端使用本地开源 ASR 模型将语音转换为文字并返回页面展示。

**核心约束：**
- 纯本地运行，不依赖云端 API
- CPU 推理，不需要 GPU
- 断网可用
- 不依赖 Docker、Node.js、数据库

---

## 二、功能需求

### 必做功能

| 编号 | 功能 | 具体要求 |
|------|------|----------|
| F1 | 浏览器麦克风录音 | 浏览器可访问麦克风、录制并停止录音；状态与时长显示；无硬编码时长限制 |
| F2 | 音频文件上传 | 可通过上传音频文件独立验证识别功能；支持常见音频格式 |
| F3 | 本地 ASR 识别 | 使用真实本地 ASR 模型分别识别中文和英文；CPU 推理 |
| F4 | 识别结果展示 | 识别结果正确返回并展示在 Web 页面 |
| F5 | 异常处理 | 能够处理常见错误，而不是直接崩溃 |

### 加分功能

| 编号 | 功能 | 具体要求 |
|------|------|----------|
| F6 | 实时语音识别 | 保持录音状态，边说边识别，文字实时追加（会议模式） |

## 三、系统接口要求

### 健康检查接口

```
GET /health
```

返回：
```json
{"status": "ok"}
```

### 语音识别接口

```
POST /api/transcribe
Content-Type: multipart/form-data
```

参数：
- `file`：音频文件（必填）
- `language`：语言选择（`zh` / `en` / `auto`，默认 auto）

返回：
```json
{
  "text": "识别出的文本",
  "language": "zh",
  "duration_seconds": 3.5,
  "processing_seconds": 1.2
}
```

## 四、技术环境要求

| 项目 | 要求 |
|------|------|
| 后端语言 | Python 3.12 |
| Web 框架 | FastAPI |
| 前端 | 原生 HTML / CSS / JavaScript（不要求框架） |
| ASR 模型 | 本地开源模型，CPU 推理 |
| 音频格式 | 支持 WAV，浏览器录音格式（WebM/Opus）需兼容 |
| 文件大小限制 | 音频文件不超过 10MB |

### 不能依赖的组件

- 云端语音识别 API
- Docker / 容器
- Node.js / npm
- 数据库
- GPU

- 语音翻译
- 文字转语音（TTS）
- 模型训练及 Fine-tuning
- 复杂的分布式部署或多用户并发系统
