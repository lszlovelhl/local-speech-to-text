## 三、已知问题与限制

1. **实时流式识别 (F6)**：未实现，当前为"录完再识别"模式。分片方案预留了扩展接口。
2. **自动语言检测**：未实现，用户需手动选择 zh/en。
3. **并发**：单用户串行处理，多用户同时请求会排队。
4. **模型精度**：base 模型在嘈杂环境或口音较重时准确率下降，可切换 small 模型提升。
