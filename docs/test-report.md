## 三、已知问题与限制

1. **说话人区分**：不支持（题目范围外），会议模式不区分谁在说话
2. **极端嘈杂环境**：浏览器降噪 + VAD 在普通办公室够用，咖啡厅/马路边识别率会下降
3. **并发**：单用户串行处理，多用户同时请求会排队
4. **模型精度**：base 模型在口音较重或嘈杂环境下准确率下降，可通过环境变量 `WHISPER_MODEL=small` 切换
